# Klebsiella AMR genomics

Research workspace for a database-derived analysis of selected *Klebsiella pneumoniae* genomic collections, intended for submission to *Antibiotics*.

## Status

Audit and cohort reconciliation are in progress. No final manuscript denominator, biological prevalence estimate, or submission-ready dataset is released here.

A result ZIP is a processing package, not necessarily a distinct SNP-cluster collection. Source metadata, versioned assembly identifiers, and verified tree linkage are required before defining biological cohorts.

## Workflow

1. Preserve source archives and record SHA-256 checksums.
2. Audit output availability, input-output identifiers, overlapping packages, and technical errors.
3. Resolve collection membership, evidence-specific denominators, and interpretation rules.
4. Generate tables and figures from reviewed records and reproducible scripts.
5. Freeze a versioned manuscript release after review.

Original ZIPs and unrestricted logs are not automatically published. Missing output is not a negative biological finding; a failed command is not a confirmed taxonomic exclusion. No transmission, plasmid co-localization, clinical phenotype validation, or population prevalence is inferred from an annotation table alone.
