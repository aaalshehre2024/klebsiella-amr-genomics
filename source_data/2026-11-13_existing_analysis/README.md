It contains 17 candidate current TSV exports, one additional draft TSV, 22 candidate Newicks, four native result TXT tables, one historical CSV, 30 result ZIPs, one analysis starter ZIP and one publication setup ZIP. No archive was extracted or repaired.

FILE_MANIFEST.csv records original file identities, sizes and SHA-256 hashes. SHA256SUMS covers the original files and generated metadata, excluding itself. ZIP_INTEGRITY.csv reports nested archive CRC/readability checks and unsafe-member warnings; 1 archive(s) require review. Damaged archives remain as original evidence.

This is a source import, not a validated manuscript release. No scientific analysis was run, no reported manuscript quantities were certified, and no tree or historical/current output selection was inferred from filenames. Assess the actual contents and provenance before analysis.
